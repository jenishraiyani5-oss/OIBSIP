This repository contains my complete task submissions for the **Oasis Infobyte Cybersecurity & Ethical Hacking Internship (OIBSIP)**. Each folder is a self-contained task covering a different area of network security, web application security, and security operations — including scope definition, tool usage, findings, and remediation guidance.

🔗 **Internship Provider:** [Oasis Infobyte](http://oasisinfobyte.com/)

## 📖 Methodology

Tasks follow industry-standard references where applicable:
- [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/)
- [PTES Technical Guidelines](http://www.pentest-standard.org/)
- [CVSS v3.1 Scoring](https://www.first.org/cvss/) for severity ratings

## 🖥️ Environment

- **Attacker/Testing Box:** Kali Linux (VMware)
- **Target(s):** Intentionally vulnerable training VMs (e.g. Metasploitable2) and local lab setups
- **Network:** Isolated VMware NAT lab subnets — no production or third-party systems involved
